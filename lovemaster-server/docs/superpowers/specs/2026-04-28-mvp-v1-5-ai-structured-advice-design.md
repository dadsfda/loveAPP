# MVP v1.5 AI 沟通建议结构化设计

**日期**：2026-04-28  
**阶段**：MVP v1.5  
**状态**：已实现  

## 背景

MVP v1.4 已接入通义千问 / 阿里云百炼 OpenAI 兼容接口，并完成一次性沟通建议能力。真实模型调用时发现，模型可能不严格返回“建议：/模板：”文本格式，导致 `messageTemplate` 无法稳定拆分。

v1.5 的目标是让 AI 接口对前端保持稳定结构：即使模型输出格式波动，接口也能返回可用的 `advice`、`messageTemplate`、`riskLevel` 和固定 `reminder`。

## 范围

本版本只优化 `POST /api/v1/ai/communication-advice` 的输出稳定性，不新增长对话、历史记忆、情绪记录持久化或关系裁判能力。

## 响应结构

```json
{
  "advice": "先表达自己的感受，再提出一个具体、可协商的请求。",
  "messageTemplate": "我感到有些委屈，是因为晚回消息让我担心。我希望下次很忙时可以简单说一声。",
  "riskLevel": "low",
  "reminder": "建议仅供参考，具体做法需要结合你们双方情况协商。"
}
```

字段规则：

- `advice`：沟通建议说明。
- `messageTemplate`：可直接参考的话术。
- `riskLevel`：只允许 `low`、`medium`、`high`。
- `reminder`：服务端固定生成，不透传模型返回。

## 解析策略

1. Prompt 要求模型只输出合法 JSON 对象。
2. 服务端优先使用 Jackson 解析 JSON。
3. 如果模型返回 Markdown 代码块包裹的 JSON，服务端先剥离代码块再解析。
4. 如果 JSON 缺字段，服务端使用保守兜底文案补齐。
5. 如果模型返回普通文本，服务端保留 v1.4 的“建议：/模板：”拆分逻辑。
6. 如果 `riskLevel` 不是 `medium` 或 `high`，统一返回 `low`。

## 安全边界

- 不保存用户输入。
- 不记录 API Key。
- 不直接信任模型返回的安全提醒。
- 不输出医疗、法律、心理诊断建议。
- 涉及自伤、暴力威胁或人身安全时，模型应返回更高风险等级，并优先提醒用户寻求现实帮助。

## 验收标准

1. 标准 JSON 返回能被稳定解析。
2. 非 JSON 文本返回仍能得到可用结构。
3. 响应包含 `riskLevel`。
4. 固定 `reminder` 不被模型覆盖。
5. 服务层和接口层测试通过。
